title=Better Containers
description=[h1]Better Containers[/h1]
description=An inventory enhancement mod that lets you control the order in which backpacks and containers are shown in each inventory, the display categories of items within, customize the container buttons and show all items in all containers (or just corpses) aka Proximity Inventory
description=[b]MOD ID CHANGE for 42.13+[/b] - it is now EURY_CONTAINERS
description=
description=[hr][/hr]
description=[h2]Features:[/h2]
description=[h3]Search[/h3]
description=[list]
description=[*]Use the Search bar to find items
description=[*]Enabled by default - disabled via Mod Options
description=[/list]
description=
description=[h3]Lock[/h3]
description=[list]
description=[*]Use the Padlock icon to Lock/Unlock Player or Loot Inventory Windows
description=[*]Enabled by default - disabled via Mod Options
description=[/list]
description=
description=[h3]Swap[/h3]
description=[list]
description=[*]Independently switch Player or Loot Container Button Panels to the left or right
description=[*]Via via Mod Options
description=[/list]
description=
description=[h3]Re-order[/h3]
description=[list]
description=[*]Drag and drop container icons for the player and loot windows into the layout you prefer (when the lock is off).
description=[*]Once set, containers will remember their position even if you unequip and later re-equip them.
description=[*]For finer control, containers can be assigned a number for sorting priority.
description=[*]Select a container and click the priority icon next to the lock icon.
description=[*]By default, dragging and dropping automatically manages the sorting priorities.
description=[/list]
description=
description=[h3]Categorize[/h3]
description=[list]
description=[*]Advanced Display Categories for items (Enabled by default - disable via Mod options)
description=[*]Category Filter (Overrides '[Y]' Drop down for sorting by size) - Allows filtering by Display Category
description=[*]Add Items to Display Category Favourites
description=[*]Chosen Items are brought to the top of the inventory list when sorted by Display Category
description=[*]Toggle favourite visibility in the player inventory via Mod Options
description=[/list]
description=
description=[h3]Customize[/h3]
description=[list]
description=[*]Alter any Container Button Name, Icon and Colour (enabled by default - disable via Mod options)
description=[*]Customize both World containers (crates etc.) and Placed Bags (Customized Bags Icons are also visible when equipped)
description=[/list]
description=
description=[h3]Proximity Inventory[/h3]
description=[list]
description=[*]Proximity and [b]Corpse Only[/b] inventory (mutually exclusive modes)
description=[*]Sandbox Options to override default behaviour/permissions
description=[*]Proximity Inventory (can be locked) Displays the contents of all inventories within range
description=[*]Corpse Only Inventory (can be locked) Displays the contents of all corpse inventories within range
description=[*]Easily switch Proximity on/off, Corpse/Proximity and lock/unlocked with key bindings (in Mod Options)
description=[*]Corpse Only mode (when locked) will only be locked to view if corpses are in range.
description=[*][b]Auto-lock mode[/b] to override/simplify lock and unlock - browse containers at will - snaps back to proximity when no other containers exist or every 10 ingame minutes unless a container was recently (10sec) selected.
description=[/list]
