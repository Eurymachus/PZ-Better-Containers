title=Better Containers
description=[h1]Better Containers[/h1]
description=An inventory enhancement mod for controlling container order, searching inventories, locking inventory windows, improving item Display Categories, pinning item types, customizing container buttons, browsing nested containers, and showing nearby containers or corpses through Proximity Inventory.
description=[b]MOD ID CHANGE for 42.13+[/b] - it is now EURY_CONTAINERS
description=
description=[hr][/hr]
description=[h2]Features:[/h2]
description=[h3]Search[/h3]
description=[list]
description=[*]Use the Search bar to find items
description=[*]Enabled by default - disable via Mod Options
description=[/list]
description=
description=[h3]Lock[/h3]
description=[list]
description=[*]Use the Padlock icon to Lock/Unlock Player or Loot Inventory Windows
description=[*]Also prevents moving or resizing locked inventory windows
description=[*]Enabled by default - disable via Mod Options
description=[/list]
description=
description=[h3]Swap[/h3]
description=[list]
description=[*]Independently switch Player or Loot Container Button Panels to the left or right via Mod Options
description=[/list]
description=
description=[h3]Re-order[/h3]
description=[list]
description=[*]Drag and drop container icons for the player and loot windows into the layout you prefer (when the lock is off).
description=[*]Once set, containers will remember their position even if you unequip and later re-equip them.
description=[*]For finer control, containers can be assigned a number for sorting priority.
description=[*]Select a container and click the priority icon next to the lock icon.
description=[*]By default, dragging and dropping automatically manages the sorting priorities.
description=[/list]
description=
description=[h3]Categorize[/h3]
description=[list]
description=[*]Advanced Display Categories for items (enabled by default - disable via Mod Options)
description=[*]Left-click the filter button to filter by Display Category; right-click to access the original weight-sorting menu
description=[*]Category Blacklist option prevents Better Containers from recategorizing configured script DisplayCategory names
description=[/list]
description=
description=[h3]Pin[/h3]
description=[list]
description=[*]Pinned Item Types, previously Category Favourites, are brought to the top of supported inventory lists
description=[*]Pinned Item Types display a small marker icon
description=[*]Toggle Pinned Item Type visibility in the player inventory via Mod Options
description=[/list]
description=
description=[h3]Customize[/h3]
description=[list]
description=[*]Alter container button Name, Icon and Colour (enabled by default - disable via Mod Options)
description=[*]Customize both world containers (crates etc.) and placed bags
description=[*]Customized bag icons are also visible when equipped
description=[*]Save, copy, paste, reset and re-use container presets
description=[/list]
description=
description=[h3]Proximity Inventory[/h3]
description=[list]
description=[*]Choose Proximity Inventory, Corpse Only Inventory, or Dual mode to show both
description=[*]Optionally hide Corpse Only Inventory when no corpses are in range
description=[*]Sandbox Options can override default behaviour and player permissions
description=[*]Proximity Inventory (can be locked) Displays the contents of all inventories within range
description=[*]Corpse Only Inventory (can be locked) Displays the contents of all corpse inventories within range
description=[*]Easily switch Proximity on/off, Corpse/Proximity and lock/unlocked with key bindings in Mod Options
description=[*]Corpse Only mode (when locked) will only be locked to view if corpses are in range.
description=[*][b]Auto-lock mode[/b] to override/simplify lock and unlock - browse containers at will - snaps back to proximity when no other containers exist or every 10 ingame minutes unless a container was recently (10sec) selected.
description=[*][b]Smart Deposit[/b] - drop items onto the Proximity Inventory to send them into nearby matching containers where possible
description=[*]Smart Deposit prefers containers with the same item type, then matching Display Categories, while respecting capacity, favourites, locked containers and access rules
description=[*]Optionally include nested container contents in Proximity Inventory - requires Loot Nested Containers to be enabled
description=[/list]
description=
description=[h3]Nested Containers[/h3]
description=[list]
description=[*]View and browse containers stored inside other containers directly from the inventory
description=[*]Nested containers can be opened without unpacking or moving them first
description=[*]Separate Mod Options for player and loot nested containers, both disabled by default
description=[*]Configurable nested container depth, parent icons and player inventory filtering
description=[*]Works alongside Re-order, Categorize and Customize where supported
description=[*]Multiplayer has additional loot-side restrictions - see Multiplayer Support below
description=[/list]
description=
description=[h3]Multiplayer Support (Build 42.21)[/h3]
description=[list]
description=[*]Better Containers supports multiplayer, but nested container browsing is more limited than in singleplayer
description=[*]Player Nested Containers supports bags inside your own inventory and carried bags, subject to your configured depth and player inventory filter
description=[*]In multiplayer, Loot Nested Containers deliberately hides bags inside world containers, on corpses, and bags on the ground because these nested loot inventories cannot be reliably resolved by the server for transfers
description=[*]The multiplayer loot-side exception is a bag directly inside an eligible vehicle compartment; deeper bags inside that bag are not supported
description=[*]Vehicle seats and containers with types containing Trunk, TruckBed or Trailer are excluded from nested loot browsing in both singleplayer and multiplayer
description=[*]To browse an unsupported loot bag, move it into your own inventory and enable Player Nested Containers
description=[*]Increasing nested depth or enabling Include Nested Containers for Proximity Inventory does not bypass these restrictions
description=[/list]
description=
description=[h3]Weight Column[/h3]
description=[list]
description=[*]Optional Weight column for player and loot inventory windows - enable via Mod Options
description=[*]Click the weight icon to switch between ascending and descending weight sorting
description=[*]Drag the column divider to resize it
description=[*]Shows stack totals and individual item weights in expanded stacks
description=[/list]
description=
description=[h3]Loot Actions[/h3]
description=[list]
description=[*]Drop items directly from loot containers using the Drop and Drop All hover buttons
description=[*]Move To Floor is also available in Proximity and Corpse Only inventories
description=[*]Move To Floor respects TwisTonFire's Blacklist when its mass-action filtering option is enabled, including corpse-only and damaged-clothing settings
description=[/list]
description=
description=[h3]Food Freshness[/h3]
description=[list]
description=[*]Optional freshness bars for spoilable food, including a marker for when food becomes stale
description=[*]Freshness percentages appear on hover and remain visible for individual items in expanded stacks
description=[*]Separate Mod Options for freshness bars and percentages
description=[/list]
description=
description=[h3]Equipped / Attached Section[/h3]
description=[list]
description=[*]Optional collapsible section grouping worn, held and attached items, plus keyrings, in the player inventory
description=[*]Enable via Mod Options
description=[/list]
